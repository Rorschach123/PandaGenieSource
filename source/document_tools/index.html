文档处理

提取、查询、编辑、创建和转换本机文档，也能导入或生成 CSV/XLSX 表格。

读取查询支持 txt、md、csv、json、xml、html、docx、xlsx、pptx、pdf。
内容编辑支持文本文件和 Office 文档中的精确文本替换。
创建表格生成 xlsx、csv、md、html、json 表格文件。
导入转换导入 CSV/XLSX 表格，或将文档转换为 txt、md、html、json。
API 示例 { "module": "document_tools", "action": "createTable", "params": { "path": "/sdcard/Documents/budget.xlsx", "headers": ["项目", "金额"], "rows": [["服务器", "800"]] } }
